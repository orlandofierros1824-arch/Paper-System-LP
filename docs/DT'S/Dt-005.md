# 🟡 DT-005: `Hardcoding de la URL base del Backend en el cliente Frontend`

| Campo | Detalle |
|-------|---------|
| **Descripción** | Las peticiones Axios en la aplicación de React utilizan direcciones `localhost` escritas directamente en los componentes en lugar de variables de entorno. |
| **Ubicación** | `frontend/src/services/api.js` |
| **Impacto** | 🟡 Medio |
| **Prioridad** | 🟡 Media |
| **Solución propuesta** | Configurar variables de entorno (`import.meta.env.VITE_API_URL`) para separar los entornos de desarrollo y producción (AWS). |
| **Esfuerzo estimado** | `S` |
| **Responsable** | `Orlando Fabian Fierros` |
| **Fecha de registro** | `2026-10-01` |
| **Estado** | `Pendiente` |

---

## 📌 Detalle Técnico
Tener URLs fijas en el código fuente impedirá desplegar correctamente el frontend en plataformas de producción en la nube sin modificar manualmente los archivos de servicio.

## ✅ Criterios de Aceptación
- [ ] Configurar archivos `.env.development` y `.env.production` con la variable `VITE_API_URL`.
- [ ] Reemplazar las cadenas estáticas de conexión en el cliente Axios.
