# 🟡 DT-004: `Manejo de errores genérico en las respuestas JSON de la API`

| Campo | Detalle |
|-------|---------|
| **Descripción** | Las excepciones del servidor devuelven trazas completas de Python o mensajes planos en lugar de un formato JSON estándar con códigos de estado HTTP claros. |
| **Ubicación** | `backend/middlewares/errorHandler.py` |
| **Impacto** | 🟡 Medio |
| **Prioridad** | 🟡 Media |
| **Solución propuesta** | Crear un manejador global de excepciones en el framework backend para estandarizar las respuestas de error hacia el cliente React. |
| **Esfuerzo estimado** | `S` |
| **Responsable** | `Miguel Angel Lobo` |
| **Fecha de registro** | `2026-10-01` |
| **Estado** | `Pendiente` |

---

## 📌 Detalle Técnico
Las respuestas de error inconsistentes dificultan que el frontend en React muestre alertas claras al usuario cuando ocurre un fallo en el servidor o en la base de datos.

## ✅ Criterios de Aceptación
- [ ] Implementar un middleware global de captura de excepciones en Python.
- [ ] Definir una estructura JSON estándar de error (`{"success": false, "message": "...", "code": ...}`).
