# BL-01: Falta de formato estándar para ubicación física

| Campo | Detalle |
|---|---|
| **Descripción** | Falta de un formato estándar para registrar la ubicación física de los productos, lo que genera datos inconsistentes y dificulta la búsqueda. |
| **Historias Relacionadas** | HU-1, HU-5 |
| **Fecha** | 07/09/2026 |
| **Tipo de Bloqueo** | Técnico / Organizacional |
| **Nivel de Escalamiento** | Equipo |
| **Intentos Previos** | Discusión interna sobre esquemas de texto libre. |
| **Acciones Propuestas** | Se propuso en el ADR-001 utilizar el código jerárquico P{n}-A{n}-E{n} (ejemplo: P1-A2-E3), almacenando pasillo, anaquel y estante en campos separados. |
| **Responsable** | Ángel (PO) |
| **Estado** | 🟢 Resuelto |
