## 🧑‍💻 About the project

### Proposed solution

A web application will be developed for **Papelería Los Piwis** to centralize the registration, consultation, and control of inventory, assigning each product a standard location code. The owner will be able to log in, register products, stock levels, and locations, and consult or search for items by name. The system will identify out-of-stock or low-stock products and classify products according to demand. This will reduce search time, improve restocking, and make better use of available space.

### ✨ Main features

- 🔐 Owner login
- 📝 Registration of products, stock levels, and locations
- 🏷️ Standard location code assigned to each product
- 🔎 Search for items by name
- ⚠️ Detection of out-of-stock and low-stock products
- 📈 Product classification according to demand

## ⚙️ Installation Guide

> ⚠️ Replace the placeholders (`<ORG-OR-USER>`, `<REPO>`, folder names, scripts) with the real values of the project.

### 1. Prerequisites

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (LTS version) and npm
- [PostgreSQL](https://www.postgresql.org/) (or Docker to run it in a container)

### 2. Clone the repository

```bash
git clone https://github.com/<ORG-OR-USER>/<REPO>.git
cd <REPO>
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Copy the example file and edit it with your own values:

```bash
cp .env.example .env
```

```env
DATABASE_URL="postgresql://USER:PASSWORD@localhost:5432/los_piwis"
JWT_SECRET="change-this-secret"
PORT=3000
```

### 5. Set up the database

```bash
npx prisma migrate dev
```

### 6. Run the system

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser and log in with the owner account.

### 🐳 Optional: run with Docker

```bash
docker compose up --build
```
